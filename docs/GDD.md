# 《三体：文明纪元》游戏设计文档 (GDD)

> 复刻《三体》小说中的 VR 游戏「三体」：带领三体行星上的文明，在三颗太阳的混沌引力中预测天象、脱水求生、积累科技，赶在下一次毁灭前飞向太空。

## 1. 一句话定位

玩家是三体文明的执政官，每回合根据天象预报做生存决策，体验「毁灭—重生—进化」的轮回，最终带领某一号文明逃出三体星系。

## 2. 核心循环（每回合 ≤4 步）

1. **看预报**：观测台给出未来 N 回合的气候预测（N = 1 + 观测台等级）。
2. **做决策**：选一个本回合行动（耕作 / 研究 / 繁衍 / 建观测台 / 星舰计划），或切换脱水状态。
3. **结束回合**：物理引擎真实推进三体运动 → 得出温度曲线 → 结算气候伤害与产出。
4. **读结果**：日志以原著文风播报事件（三日凌空、飞星不动、文明毁灭……）。

## 3. 物理系统（真实三体模拟）

- 3 颗太阳（质量 1.0，G=1）+ 行星（质点），2D 速度 Verlet 积分，dt=0.002，每回合 400 子步。
- 初始条件随机生成，但**亮度标定**使开局温度 = 20°C（保证可玩开局），之后全靠混沌演化。
- 温度模型（x = flux/flux₀，开局标定 T=20°C）：x≤1 时 `T = 20 + 25·ln(x)`（下限 -100），x>1 时 `T = 20 + 45·(x-1)`——远日平滑入寒，近日线性升温，凌空为稀有尖峰。
- 行星被吞噬（d < 0.008）→ 文明毁灭 + 星系重置；被甩出（连续 12 回合 min d > 25）→ 同上。
- 开局星系筛选：40 回合内无吞噬/甩出、前 6 回合无凌空、≥1/4 回合可生产（30 次抽样取最优）。
- 预报 = 真实前向积分（确定性），观测台等级决定可见步数；视野之外显示「？」。

## 4. 气候分级与效果

| 温度 T (°C) | 名称 | 含水效果/回合 | 脱水效果/回合 |
|---|---|---|---|
| 凌空毁灭（avgT≥800 或 maxT≥1600） | 烈日凌空 | **文明毁灭** | 人口 -80%（深藏地窟者存活），粮食 -50% |
| 280–800 | 双日凌空 | 人口 -85%，粮食 -80% | 人口 -30% |
| 90–280 | 炙烤 | 人口 -40%，粮食 -30%，产出 ×0 | 人口 -1.5% |
| 45–90 | 酷热 | 人口 -10%，产出 ×0.5 | 人口 -0.5% |
| 8–45 | 温和（连续3回合→恒纪元） | 正常产出 | 人口 -0.5%（风干损耗） |
| -25–8 | 寒冷 | 人口 -8%，产出 ×0.5 | 人口 -0.5% |
| -75–-25 | 严寒 | 人口 -35%，产出 ×0 | 人口 -1% |
| < -75 | 极寒 | 人口 -55%，产出 ×0 | 人口 -1.5% |

- 瞬时尖峰 maxT≥800 但未达毁灭线时，降格按双日凌空结算（掠日尖峰）。

- **恒纪元**判定：温和气候连续 ≥3 回合后才标注为恒纪元（前几回合仍视作乱纪元间隙）。
- **浸泡**只允许在 T∈[-10, 50] 时执行，否则额外死亡 30%（原著：在烈日下浸泡即焚毁）。
- **三星连珠**（三颗太阳近似共线且距离近）：引力潮汐，人口 -15%。
- **飞星**：太阳距离 > 6 时显示为飞星；三飞星 = 极寒前兆（纯天象演出 + 日志提示）。

## 5. 数值系统

资源：**人口**(万)、**粮食**、**科技**、**观测台等级**(0–6)、**脱水状态**。

- 开局：人口 10，粮食 50，科技 0（继承时见 §6），观测台 0，**脱水蛰伏状态**（等首个温和窗口浸泡苏醒）。
- 每回合粮耗：`人口 × 0.5`；缺粮饥荒：人口按缺口比例（缺粮/所需粮）死亡（上限 35%/回合）。
- 气候宜人且有余粮时人口每回合自然增长 5%×气候系数（向上限收敛，不占行动）。
- 脱水期间「守夜学者」以 `人口 × 0.12 × 时代倍率` 速率积累科技。
- 时代门槛（科技值）：石器 0 → 青铜 25 → 铁器 75 → 蒸汽 180 → 电气 400 → 原子 700 → 信息 1100 → **太空 1600**。
- 时代产出倍率：1 / 1.3 / 1.7 / 2.2 / 3 / 4 / 5.5 / 7。
- 人口上限（按时代）：30 / 60 / 120 / 250 / 500 / 900 / 1500 / 2500。
- 行动：
  - **耕作**：粮 += 人口 × 1.5 × 时代倍率 × 气候产出系数。
  - **研究**：科技 += 人口 × 1.5 × 时代倍率 × max(气候系数, 0.5)。
  - **繁衍**：人口向上限逻辑增长 12% × 气候系数，额外粮耗 0.3/万人。
  - **建观测台**：粮 -30×(等级+1)，等级 +1。
  - **星舰计划**（太空时代解锁）：投入 3 次，每次粮 -200 → **胜利**。
  - **静待**：什么都不做让时间流逝（脱水熬灾难的主要手段）。
  - **全民脱水 / 集体浸泡**：切换状态，占用回合。脱水期间不耗粮、免疫多数灾害。
  - **繁衍**额外粮耗按新增人口 ×0.3 计。

## 6. 胜负与轮回

- **失败**：人口 < 0.5 万，或凌空级灾难，或行星被吞噬/甩出 → 当前文明毁灭。
- **轮回**：文明编号 +1，科技继承 75%（向下取整），观测台等级继承一半（向上取整），人口/粮食重置，新文明以脱水种子形态蛰伏；日志用原著句式播报（"第 N 号文明在烈焰中毁灭了……文明的种子仍在……"）。吞噬/甩出时连星系一起重置（重新筛选）。
- **胜利**：完成星舰计划 → 结局画面（"你们飞出了三体星系……但黑暗森林正注视着这一切"），可继续无尽模式或重开。
- 文明编号从 137+random(0,30) 起——玩家接入时，三体世界已轮回了上百次。
