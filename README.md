# 三体：文明纪元

复刻《三体》小说中的那款 VR 游戏「三体」——你是三体行星文明的执政官，在三颗太阳真实的混沌引力中预测天象、脱水求生、积累科技，赶在下一次毁灭之前，带领文明飞向太空。

## 怎么玩

**双击 `index.html` 即可开始**（无需安装、无需服务器、无需联网）。

- 文明以**脱水种子**形态开局：看左下角天象预报，等到「温和」纪元，点击 **🌊 集体浸泡** 唤醒文明。
- 恒纪元（温和气候持续 3 回合以上）：抓紧 **🌾 耕作 / 🔬 研究 / 👥 繁衍**。
- 预报里出现红色「凌空」或深紫「极寒」：立刻 **💧 全民脱水**，然后 **⏳ 静待** 熬过去。
- **🔭 建观测台**提升预报视野（1 + 等级 回合），这是活下去的关键投资。
- 科技达到**太空时代**后，投入 3 次 **🚀 星舰计划** → 胜利。

文明毁灭并非终点：下一号文明将继承 75% 科技与一半天文知识，从废墟上重新开始——直到某一号文明逃出三体星系。

## 特性

- **真实三体物理**：三颗太阳 + 行星的引力系统用速度 Verlet 积分真算，恒纪元/乱纪元是混沌动力学的自然涌现，不是脚本。
- **天象即信息**：太阳的视大小、飞星、三星连珠都来自真实模拟；预报是对未来的确定性积分，观测台等级决定你能看多远。
- **原著事件**：三日凌空、双日凌空、飞星不动、三星连珠、脱水、浸泡、文明编号轮回……日志以原著文风播报。
- 经过 100+ 局自动化模拟调平衡：硬核 roguelike 难度，残酷即正义。

## 项目结构

```
index.html      页面骨架
style.css       深空风格样式
js/physics.js   三体物理引擎（积分器/温度模型/预报）
js/game.js      游戏逻辑（数值/结算/轮回/胜负）
js/ui.js        渲染（天象画布/面板/日志）
js/main.js      入口与事件绑定
docs/GDD.md     完整设计文档（全部数值的唯一依据）
```

调试接口：浏览器控制台 `window.__tb.state` 查看状态，`window.__tb.act('farm')` 执行动作。
